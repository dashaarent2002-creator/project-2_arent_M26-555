# Primitive DB

Простая консольная база данных на Python. Умеет создавать и удалять таблицы,
добавлять, читать, обновлять и удалять записи. Данные хранятся в JSON-файлах:
структура таблиц в `db_meta.json`, записи каждой таблицы в `data/<имя_таблицы>.json`.

## Установка

Нужен [uv](https://docs.astral.sh/uv/).

```bash
uv sync          # или: make install
```

Сборка и установка пакета как отдельной команды:

```bash
uv build                       # или: make build
uvx twine check dist/*         # или: make check-package
uv tool install dist/*.whl     # или: make package-install
```

## Запуск

```bash
uv run database   # или: make run
```

После установки пакета через `uv tool install` достаточно набрать `database`.

## Управление таблицами

| Команда | Что делает |
|---|---|
| `create_table <имя> <столбец:тип> ...` | создать таблицу (столбец `ID:int` добавляется автоматически) |
| `list_tables` | показать список всех таблиц |
| `drop_table <имя>` | удалить таблицу (с подтверждением) |
| `help` | справка |
| `exit` | выход |

Поддерживаемые типы: `int`, `str`, `bool`.

```
>>>Введите команду: create_table users name:str age:int is_active:bool
Таблица "users" успешно создана со столбцами: ID:int, name:str, age:int, is_active:bool
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
```

## CRUD-операции

| Команда | Что делает |
|---|---|
| `insert into <таблица> values (<знач1>, <знач2>, ...)` | добавить запись (ID создается автоматически) |
| `select from <таблица>` | показать все записи |
| `select from <таблица> where <столбец> = <значение>` | показать записи по условию |
| `update <таблица> set <столбец> = <значение> where <столбец> = <значение>` | обновить запись |
| `delete from <таблица> where <столбец> = <значение>` | удалить запись (с подтверждением) |
| `info <таблица>` | информация о таблице |

Строковые значения пишутся в кавычках, логические как `true` / `false`.

```
>>>Введите команду: insert into users values ("Sergei", 28, true)
Функция insert выполнилась за 0.000 секунд.
Запись с ID=1 успешно добавлена в таблицу "users".
>>>Введите команду: select from users where age = 28
Функция select выполнилась за 0.000 секунд.
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei |  28 |    True   |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: delete from users where ID = 1
Вы уверены, что хотите выполнить "удаление записи"? [y/n]: y
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок и декораторы

- `handle_db_errors` перехватывает ошибки (несуществующая таблица или столбец,
  неверный тип значения, отсутствующий файл) и выводит понятное сообщение
  вместо падения программы.
- `confirm_action` спрашивает подтверждение перед опасными действиями
  (`drop_table`, `delete`). Любой ответ, кроме `y`, отменяет операцию.
- `log_time` показывает время выполнения `insert` и `select`.
- `create_cacher` — замыкание, которое кэширует результаты одинаковых запросов `select`.

## Структура проекта

```
src/primitive_db/
├── __init__.py
├── main.py        # точка входа
├── engine.py      # главный цикл и разбор команд
├── core.py        # логика таблиц и CRUD
├── parser.py      # разбор values / where / set
├── utils.py       # работа с файлами
├── decorators.py  # декораторы и кэширование
└── constants.py   # константы
```
